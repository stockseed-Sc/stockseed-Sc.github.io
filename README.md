# 주식새싹 (주식 AI 사이트 키트 · 초보 교육형)

- 사이트 설정: `config.json`
- **주식 용어사전: `glossary.json`** (용어 109개, 자유롭게 추가·수정) → `/glossary/`와 용어별 페이지 자동 생성.
  시세와 관련된 용어에는 '오늘의 실제 예시'를 그날 숫자로 붙입니다.
- 고유 기능: 용어사전, 종목 페이지 '이 숫자는 무슨 뜻일까요?' 풀이 박스, 쉬운 말 AI 해설,
  메인 '오늘의 용어'(매일 바뀜) + '초보 체크리스트'
- 로컬 미리보기: `DEMO_NEWS=1 python build.py --demo` → `python -m http.server 8000 --directory site`
- 배포 전 `site/`, `posts/` 폴더는 지우세요 (데모 데이터).
